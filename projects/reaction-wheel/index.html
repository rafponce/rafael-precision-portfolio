01

Problem

A control algorithm has to work with the inertia, sensing, motor response, and disturbances of real hardware. Our senior design project combined a reaction-wheel assembly with closed-loop attitude control.

The four-wheel diagonal architecture used an Arduino UNO R4, a BNO085 IMU, Nidec brushless servo motors, encoder feedback, and 3D-printed and machined parts. Physical yaw and pitch control were demonstrated; full three-axis stabilization remained incomplete.

Concepts

Separate the control functions

ITERATION / 02

Test the complete loop

Tune with the physical assembly and examine the measured response, rather than relying only on commanded output.

04

Engineering Analysis

A reaction wheel exchanges angular momentum with its supporting body. Motor torque changes wheel momentum, producing an opposing torque on the structure.

The controller uses measured attitude error to command that exchange. Proportional, integral, and derivative behavior must be tuned with actuator limits, sensor behavior, and the actual test setup in mind.

05

Design

The four diagonally mounted wheels were supported by a gimbal-style test structure. IMU initialization and zeroing fed PID control, PWM mixing, and live telemetry. Stop and brake functions provided a way to interrupt the experiment.

The prototype was built as a demonstration and test platform. This portfolio does not present it as a flight-qualified attitude-control unit.

06

Build / Test

Physical testing demonstrated 360° yaw control, approximately 15° pitch motion, and recovery from disturbances in the tested setup.

A minimum yaw error of approximately 1.34° was observed. That figure describes the reported test result, not a guaranteed accuracy across all attitudes or operating conditions.

07

Results

The prototype connected embedded control with observable hardware behavior. Telemetry and repeatable tests made it possible to evaluate the system beyond whether the wheels simply spun.

360°yaw control demonstrated
15°pitch motion demonstrated
~1.34°minimum yaw error observed
08

What I Learned

The complete loop matters. Sensor offsets, control gains, wheel response, and the mechanical setup all affect the behavior. Physical testing made the relationship between a control decision and the resulting motion much clearer.
