Midsole Foam Performance Simulation Platform

Make foam, thickness, and layer tradeoffs visible before committing to a physical midsole.

01

Problem

A single hardness value cannot describe how an entire foam package responds through compression. Product engineers needed a way to compare materials, stack heights, and layer combinations using behavior relevant to a shoe.

I developed a simulation-driven performance library and an expandable Excel dashboard that connected nonlinear analysis with mechanical testing. The goal was to make tradeoffs in stiffness, bottoming-out, energy return, and cost easier to understand.

Concepts

ITERATION / 01

Start with a baseline

Use soft, medium, and firm foams to establish a manageable comparison set before expanding the construction space.

ITERATION / 02

Separate the variables

Compare material, thickness, and layer count deliberately, so a difference in response can be connected to a design decision.

04

Engineering Analysis

I ran 70+ Abaqus Explicit nonlinear simulations using C3D10M elements. Large deformation, contact, and the foam response made the modeling choices consequential. The simulations were compared with physical compression behavior, rather than treated as a standalone answer.

A mesh study stepped from 4 mm to 2 mm, 1.5 mm, and 1 mm. I selected 2 mm: it stayed within 1.11% of the converged response while reducing runtime by approximately four times. The comparison was specific to this study, not a universal mesh prescription.

05

Design

The library organizes materials and single- to multi-layer constructions behind an Excel interface. Automated force–displacement plots and secant-stiffness calculations allow engineers to compare packages at different stages of compression.

I divided the response into 0–25%, 25–50%, and 50–75% compression ranges. This makes it easier to see why a foam that feels compliant initially can behave differently as compression increases.

06

Build / Test

Mechanical compression testing used a footform/last on the B140 system at 1 Hz. Bonded 200 × 200 × 20 mm foam slabs supported the baseline and layer comparisons.

The study integrated 22 test curves. I compared loading and unloading behavior, force–displacement response, and energy efficiency to understand where the models represented the physical tests and where further investigation was needed. The physical comparisons identified a material-model accuracy gap despite consistent relative trends across soft and firm constructions.

07

Results

The result was an expandable engineering reference that made foam-package comparisons repeatable and easier to communicate. The selected mesh retained the study’s response accuracy while reducing iteration time.

What I Learned

The useful output is not simply a successful simulation. It is a comparison an engineer can act on. Working between the test lab, the models, and the product team taught me to connect numerical fidelity with the decisions the tool was meant to support.
